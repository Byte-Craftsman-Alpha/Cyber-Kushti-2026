  prior_analysis.md      the first-pass reconstruction that preceded this work:
                         root causes RC1 to RC9, a stage sequence, evidence gaps,

Both are reproduced here unmodified so that anyone receiving the kit can see
exactly what the report was working from. Everything in this kit that refers to a
finding number (F1, F32) refers to the case study, and everything that refers to a
root cause (RC1, RC9) refers to the prior analysis.
